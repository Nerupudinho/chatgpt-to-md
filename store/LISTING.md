## Short Summary (≤132 characters)

Export any ChatGPT conversation to a clean Markdown file. One click to download locally.

## Detailed Description

Download your ChatGPT conversations as clean, portable Markdown files.

**How it works:**
• Open any conversation on chatgpt.com
• Click the "Download .md" button (bottom-right corner)
• Get a properly formatted Markdown file saved to your device

**Features:**
• Preserves conversation structure with clear speaker labels
• Formats code blocks with syntax highlighting markers
• Handles lists, tables, links, and other formatting
• Works with the latest ChatGPT interface
• Zero configuration required

**Perfect for:**
• Archiving important conversations locally
• Importing chats into note-taking apps (Obsidian, Notion, etc.)
• Using conversations as context for other AI tools
• Creating documentation from ChatGPT outputs
• Keeping offline backups of your work

**Privacy:**
This extension runs entirely in your browser. Your conversations are never sent to external servers. No data collection, no analytics, no accounts required.

**Open Source:**
The complete source code is available on GitHub for review.
