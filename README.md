# ChatGPT to Markdown

A Chrome extension that downloads any ChatGPT conversation as a clean `.md` file with one click.

## How to Use

1. Load unpacked in `chrome://extensions` (Developer mode on)
2. Open any ChatGPT conversation at `chatgpt.com`
3. Click the **Download .md** button injected into the page
4. A `.md` file is saved to your Downloads folder

## Stack

JavaScript · Chrome Extensions Manifest V3
